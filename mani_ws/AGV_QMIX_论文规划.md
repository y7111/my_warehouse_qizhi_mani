# AGV QMIX 论文规划

> 最后更新：2026-05-16

---

## 一、研究方向定位

### 当前项目的学术价值

本项目属于**跨领域应用研究**，横跨两个方向：

```
多智能体强化学习（MARL）  ×  多机器人仓库调度
        ↓
把 QMIX 算法应用到多AGV任务分配场景
加上实车（Jetson NX）部署验证
```

**核心优势：有实车**。大多数相关论文只做仿真，实车验证是审稿人非常看重的加分项。

## 二、研究现状梳理

### QMIX 改进类论文在做什么？

改进 QMIX 的论文研究的是**算法本身**，不针对任务分配场景：

| 论文 | 年份 | 核心贡献 | 测试环境 |
|---|---|---|---|
| QMIX | 2018 | 单调值分解基础框架 | StarCraft II |
| WQMIX | 2020 | 解决单调性约束过强问题 | StarCraft II |
| QPLEX | 2021 | 提升值函数分解表达能力 | StarCraft II |

这些论文用星际争霸验证，**与仓库场景无关**，是纯算法研究。

### 多机器人任务分配在做什么？

任务分配是独立领域，方法多样：
- 传统方法：匈牙利算法、拍卖算法、整数规划
- 强化学习：QMIX 是其中一种选择

### 用 MARL 做路径规划有没有人研究？

有，方向叫 **MAPF + RL**，代表工作：
- PRIMAL（2019）：RL 做多机器人路径规划
- DHC（2021）：加通信机制的 MARL 路径规划

**但结论不乐观**：经典算法 CBS 在路径规划上比 QMIX 更快更优，学术界主流结论是"路径规划用经典算法，任务分配用 MARL，两层分开做效果最好"。

## 三、推荐创新方向

### 方向1：注意力机制 QMIX（最推荐）

**问题：** 标准 QMIX 把所有货架信息直接拼接，不知道哪个更重要。

**创新：** 加入 Attention 机制，让每辆车自动聚焦最相关的货架。

```
标准QMIX：    所有货架信息 → 直接拼接 → 决策
Attention-QMIX：所有货架信息 → 注意力加权 → 聚焦关键货架 → 决策
```

**价值：** 货架越多、AGV越多，效果越明显，扩展性好，实现难度适中。

---

### 方向2：带通信的 QMIX

**问题：** 车辆虽能看到彼此位置，但没有主动"沟通意图"。

**创新：** 决策前互发意图向量，告知对方自己的计划。

```
标准QMIX：  看到其他车位置 → 决策
CommQMIX：  位置 + 收到其他车意图向量 → 更好协作
```

---

### 方向3：分层 QMIX

**问题：** 直接决策具体货架，任务粒度过细。

**创新：** 两层决策——上层分配区域，下层在区域内选货架。

---

### 方向4：QMIX（任务分配）+ CBS（路径规划）组合

**问题：** 当前用 A* 做路径规划，多车同时移动时可能死锁。

**创新：** 用 CBS（Conflict-Based Search）替换 A*，保证多车路径全局最优、无死锁。

**CBS 优势：**
```
A*：  单车最优路径，多车冲突靠简单等待解决
CBS： 同时规划所有车的路径，保证全局最优，无死锁
```

**这个组合（改进QMIX任务分配 + CBS路径规划）在仓库场景研究不多，是真正的空白点。**
