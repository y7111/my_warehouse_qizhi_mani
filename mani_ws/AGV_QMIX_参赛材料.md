# 一、技术报告

## 1. 项目背景

智慧仓储是工业4.0的核心场景之一。传统多AGV调度依赖人工规则（如优先级队列、静态路线规划），难以应对动态货物补充、多车竞争资源等复杂情况。本项目以"多车协同货物搬运"为核心任务，采用多智能体强化学习（MARL）方法，实现自适应的任务分配决策，并在真实机器人平台上完成部署。

## 2. 系统总体架构

系统采用**两层分离架构**：

```
高层决策（QMIX + Attention）
    → 输出：每辆车的目标位置（去哪个货架 / 哪个投递区）
低层导航（A* 路径规划）
    → 输出：具体行走路径，每步走一格
实车执行（ROS1 + Jetson NX）
    → 订阅目标点，驱动底盘运动
```

选择此架构的核心理由：QMIX 端到端路径规划训练难度极高（需数周），而 A* 已有成熟实现。QMIX 专注"谁去哪"的任务分配，是在1个月内可落地的最优技术路线。

## 3. 仿真环境设计

**地图**：20×16 十字形网格，包含北臂、南臂、横臂三段走廊。

关键设计：
- **瓶颈通道**：北臂(R3)和南臂(R11)各仅有2格通道，强制4辆车协商进出顺序
- **走廊隔墙**：横臂R7有隔墙，货架需绕行，路径多样
- **10个货架**：分布于北臂和横臂四角，货物类型（A/B/C）动态随机刷新
- **3个投递区**：A/B/C分别位于南臂固定位置
- **补货延迟**：货架被取货后空置40步，迫使智能体感知库存状态

**观测向量（87维）**：
```
self_feat(19)  = 自身坐标(2) + 携带状态one-hot(4) + 当前目标one-hot(13)
other_feats(18) = 其他3辆车 × (坐标(2) + 携带状态(4))
shelf_feats(50) = 10货架 × (货物类型one-hot(3) + 坐标(2))
```

**全局状态（74维）**：4辆车位置与携带状态 + 10货架货物类型与坐标，仅在训练时用于混合网络。

**动作空间（13个离散动作）**：动作0-9对应10个货架，动作10-12对应投递区A/B/C。决策时机为任务完成时触发，而非每步触发。

## 4. QMIX 算法

QMIX 是一种多智能体值分解算法，核心思想是将联合动作值函数 $Q_{tot}$ 分解为各智能体局部 $Q_i$ 的单调组合：

$$Q_{tot}(\mathbf{a}, s) = f_{\phi}(Q_1(o_1, a_1), ..., Q_n(o_n, a_n), s)$$

混合网络通过**超网络（Hypernetwork）**从全局状态生成混合权重，并对权重取绝对值保证单调性（IGM条件），从而使联合策略可以由各智能体的局部贪婪策略完全还原，支持去中心化执行。

**奖励设计（团队共享）**：
| 事件 | 奖励 |
|---|---|
| 正确投递货物 | +10 |
| 错误投递货物 | -10 |
| 每个时间步 | -0.05 |

## 5. 网络结构：AttentionAgentQNet

本项目核心创新在于将 Multi-Head Attention 嵌入单智能体 Q 网络，形成**双路注意力架构**：

**货架注意力（Shelf Attention）**
- Query：自身特征 self_feat(19) → Linear → d_model(32)
- Key/Value：10个货架特征 → Linear → d_model(32)
- 输出货架上下文向量 shelf_ctx(32)
- 物理含义：让每辆车"选择性关注"当前最值得去的货架

**车间注意力（Agent Attention）**
- Query：自身特征 → Linear → d_model(32)
- Key/Value：其他3辆车特征 → Linear → d_model(32)
- 输出协作上下文向量 agent_ctx(32)
- 物理含义：感知其他车的位置与任务，避免重复分配

**输出分支（解耦设计）**
```
货架头：[self_feat(19) || shelf_ctx(32) || agent_ctx(32)] → MLP(128) → Q(0~9)
投递头：self_feat(19) only → MLP(64) → Q(10~12)
```
投递头刻意隔离 Attention 上下文，避免货架感知信号干扰投递决策。

**参数共享**：4辆车使用同一套网络参数，减少样本需求，加速收敛。

对照基线 **MLPAgentQNet**：两层 MLP(hidden=64)，参数量约为 Attention 版本的 1/3，用于消融实验。

## 6. 训练策略

**为什么不在 Gazebo 中训练**：Gazebo 以实时速度运行，每 episode 约数分钟，训练6000轮需数月，超出比赛时限。

**两阶段训练流程**：
1. **阶段一（纯Python仿真）**：数小时收敛，验证策略有效性，保存最优 checkpoint
2. **阶段二（Gazebo验证）**：加载 checkpoint 直接推理，修正 sim-to-real 差异
3. **阶段三（实车部署）**：Jetson NX 边缘推理，TorchScript 导出加速

**关键超参数**：
| 参数 | 值 | 说明 |
|---|---|---|
| 训练轮数 | 6000 episodes | |
| 经验回放池 | 20000 | |
| 批大小 | 32 | |
| 学习率 | 2e-4 | 降低防止Q值震荡 |
| ε衰减 | 1500 ep | 快速收敛后维持底线探索(0.1) |
| Target网络更新 | 每100 ep | 保持目标网络稳定 |
| 折扣因子 γ | 0.99 | |

## 7. 实验结果

### 7.1 训练收敛

Attention-QMIX 在约 800 episode 后显著收敛，最优 checkpoint 为 `checkpoints_v5_attn/qmix_ep800.pt`。训练曲线稳定上升，最后200 episode 均值达到全程最高200 episode 均值的 90% 以上，满足收敛判定条件。

### 7.2 对照实验（贪婪评估，100 episodes）

| 方法 | 每轮完成任务数 | 相对随机基准提升 |
|---|---|---|
| 随机策略 | ~3-4 次 | 基准 |
| MLP-QMIX（hidden=64）| 17.8 次 | +4~5x |
| **Attention-QMIX（本方案）** | **19.0 次** | **+5x，优于MLP 6.5%** |

两方案训练轮数、超参数完全相同，差异仅在网络结构，对比结论可信。

### 7.3 Attention 可解释性

输出 25 次完整投递过程的 Attention 权重序列，制作成4 agent × 25 step 热力图（`attention_heatmap.png`）。结果表明：
- 空手的车对有货货架的 Attention 权重明显更高
- 多辆车倾向于分散关注不同货架，表现出自发的任务分工
- Attention 权重随时间步动态变化，验证网络在主动感知环境

## 8. Gazebo 仿真验证

在 ROS1（Noetic）环境下搭建 20×16 十字形 Gazebo 仿真场景，4辆启智MANI小车加载训练好的 QMIX checkpoint 进行推理。

系统接口：
- QMIX 推理节点订阅各车位置（/tf）和货物状态（cargo_manager）
- 输出目标 waypoint 发布至 `/waterplus/navi_waypoint`
- A* 路径规划由 ROS 导航包负责底层执行
- RViz 中实时可视化 Attention 权重（以货架标注颜色深浅表示）

验收条件：4辆车在 Gazebo 中完成至少一轮完整取货-投递流程，RViz 可见 Attention 权重变化。

## 9. 实车部署

目标平台为**启智MANI + Jetson NX**（ROS Melodic）。

部署步骤：
1. `torch.jit.script()` 导出 TorchScript 模型，消除 Python 依赖
2. ROS 推理节点：订阅 `/tf` 与货物状态，以 10Hz 频率运行 QMIX 推理，发布 waypoint
3. 简化场景优先验证：2辆车 + 4货架 + 2类货物，验证通过后扩展至4车完整场景
4. 机械臂抓取：到达货架位置触发固定角度抓取指令（`/wpb_mani/grab_box`）

## 10. 总结

本项目构建了完整的多AGV智能调度系统，核心贡献：
1. **双路注意力 Q 网络**：货架感知 + 车间感知，决策可解释
2. **分层架构**：QMIX 任务分配 + A* 导航，工程可落地
3. **对照实验**：量化证明 Attention 机制带来 6.5% 性能提升
4. **端到端闭环**：从仿真训练到实车推理的完整技术链路

## 第8页 · QMIX 算法原理

**标题**：QMIX：让协作有数学保证

**左侧核心公式**：
$$Q_{tot} = f_\phi(Q_1, Q_2, Q_3, Q_4,\ s)$$
混合网络权重由全局状态 $s$ 生成，取绝对值保证单调性（IGM条件）

**右侧架构示意图**：
```
Agent1 obs → Q1 ──┐
Agent2 obs → Q2 ──┤→ 混合网络(超网络) → Q_tot → 梯度回传
Agent3 obs → Q3 ──┤    ↑
Agent4 obs → Q4 ──┘  全局状态 s
```

**底部一句话**：去中心化执行 + 集中式训练，实车无需通信

## 第9页 · 核心创新：双路Attention网络

**标题**：AttentionAgentQNet — 让每辆车"有意识地感知"

**主体结构图**：
```
              自身特征(19维)
             ╱              ╲
    货架注意力               车间注意力
  Q←self_feat            Q←self_feat
  K/V←10个货架           K/V←其他3辆车
  → shelf_ctx(32)        → agent_ctx(32)
             ╲              ╱
    拼接 [self(19)‖shelf_ctx(32)‖agent_ctx(32)]
                    ↓
              货架选择头 → Q(0~9)
              投递选择头 → Q(10~12)  ← 仅用self_feat，隔离干扰
```

**右侧文字说明**：
- 货架注意力：动态感知"哪个货架最值得去"
- 车间注意力：感知队友位置，避免重复分配
- 投递头隔离：有货时决策不受货架感知干扰
